# FreshStart starter 💚

A tiny website (HTML + CSS + JavaScript) to start your FreshStart project from.
It runs in **GitHub Codespaces**, a full coding setup in your browser, so you don't need to install anything.

---

## 1. Make your team's copy (one person per team)

1. Click **Use this template → Create a new repository**.
2. Give it a name, set it to **Public**, and click **Create repository**.
3. Add your teammates: **Settings → Collaborators → Add people**, then search for their GitHub usernames.
   Teammates: accept the email invite (or the banner at the top of the repo page).

> Use **Create a new repository**, not "Open in a codespace". That way your work is saved on GitHub and you can put it online later.

## 2. Open your codespace (everyone)

On **your team's repo** (not the template):
**Code → Codespaces → Create codespace on main**

It takes about a minute to load. `index.html` and this README open automatically.

## 3. Edit and preview

1. In `index.html`, change `Hello, W&M!` to something of your own.
2. Right-click `index.html` in the file list → **Show Preview**. Your site opens in a new browser tab.
3. Edit, and the preview updates on its own. (Files save automatically.)

No preview? Open the **Ports** tab at the bottom, find port **3000**, and click the 🌐 globe icon.
Or run this in the terminal: `python3 -m http.server 8000`

## 4. Save your work to GitHub (commit + push)

1. Click the **Source Control** icon on the left (the branching lines).
2. Type a short message like `Changed the heading`.
3. Click **Commit**, then **Sync Changes**.

Do this often. **Before you start working, click Sync Changes** so you have your teammates' latest work.
Tip: to avoid clashing changes, have teammates work on different files.

## 5. Put it online (GitHub Pages)

1. On your repo page, go to **Settings → Pages**.
2. Under "Build and deployment", choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
3. Wait a minute and refresh. Your link appears at the top: `https://YOUR-USERNAME.github.io/REPO-NAME/`

Every time you push, the site updates within a minute or two. Put this link in your pitch!

## Good to know

- **It's free.** Every GitHub account gets about 60 hours a month on the default machine. You never need a credit card; if hours run out, codespaces just pause until next month.
- **Stop your codespace when you leave.** It stops by itself after 30 minutes of no activity, but stopping it saves hours. Go to [github.com/codespaces](https://github.com/codespaces) → `…` → **Stop codespace**.
- **Come back later** from [github.com/codespaces](https://github.com/codespaces). Your codespace keeps your files.
- **Share a preview with your team:** Ports tab → right-click the port → **Port Visibility → Public**. That link only works while your codespace is running. For a link that keeps working, use GitHub Pages.
- **Student?** Get extra Codespaces hours and free Copilot at [github.com/education/students](https://github.com/education/students). Approval can take a while, so you don't need it for this weekend.
